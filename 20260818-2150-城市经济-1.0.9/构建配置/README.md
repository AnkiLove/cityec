# 城市经济

适用于 Minecraft 1.20.1 Fabric 的独立经济模组，模组 ID 为 `cityec`。提供现金、银行卡、自动柜员机和收银机，面向城市和角色扮演服务器的基础交易流程。

## 主要功能

- 1、5、10、20、50、100 元六种现金，所有现金单组上限固定为 50 个。
- 城市银行卡：余额保存在物品数据中，悬停时显示当前余额。
- 自动柜员机：打开界面后必须把银行卡放入插卡槽；选择 100、50、20、10、5 或 1 元后确认取款，也可以把手持现金逐张存入插槽中的银行卡。
- 收银机：单格高度，打开界面后可插入银行卡付款，或使用背包中的现金组合支付并自动找零。
- 城市扳手：右键 ATM 或收银机打开配置界面，可切换启用状态并用加减按钮调整单次取款金额或收款金额。
- 管理命令：`/cityec balance` 查看第一张银行卡余额；管理员可用 `/cityec give <金额>` 发放现金。

## 运行环境

- Minecraft 1.20.1
- Fabric Loader 0.15 或更高版本
- Fabric API 0.92.2+1.20.1
- Java 21

## 构建

本机没有全局 Gradle 时，请使用 Gradle 8.14 或更高版本（本项目已用 Gradle 9.5 验证）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Zulu\zulu-21'
gradle build
```

构建结果位于 `build/libs/cityec-1.0.9.jar`。将该文件与 Fabric API 一并放入服务端和客户端的 `mods` 目录。

## 基本使用

1. 获取银行卡、现金、自动柜员机、收银机和城市扳手。
2. 右键 ATM 打开界面，将银行卡放入插卡槽，再选择取款面额或存入手持现金。
3. 右键收银机打开付款界面；银行卡支付必须放入插卡槽，现金支付会自动组合面额并找零。
4. 手持城市扳手右键设备，调整开关和金额后保存设置。

## 配方

- 银行卡：金锭、纸、铁锭、红石。
- 城市扳手：铁锭和木棍。
- 自动柜员机：铁锭、红石和木桶。
- 收银机：铁锭、红石、箱子和纸。
